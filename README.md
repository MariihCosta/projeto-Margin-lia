# projeto-Margin-lia
O projeto Marginália é um clube do livro desenvolvido em HTML e CSS, com foco em uma interface elegante, acessível e intuitiva. Apresenta a leitura do mês, informações sobre o clube e participação dos leitores, além de oferecer alternância entre os modos claro e escuro. A identidade visual valoriza o conforto e a experiência de leitura.
